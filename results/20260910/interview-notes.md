# 面试讲解记录

当前已完成 30 轮每轮 300 请求的阶段性性能实验和成本标定。以下提纲用于解释已有证据，未完成的大样本验证不得写成最终结论。详细结果见本目录 README 和 ../../docs/experiment-status.md。

## 三分钟讲解

1. 问题：16K 输入命中 12K，仍需算 4K；2K 输入命中 1K，只需算 1K。最大缓存命中不必然对应最短 prefill。
2. 原生依据：比较固定版本 FCFS、LPM、DFS-weight、HRRN；HRRN 已有未缓存长度和 token 等待老化，不能把它作为自己的创新。
3. 实现：只改变等待队列顺序；比较输入长度、剩余 token、墙钟超阈值提升和实测成本估计；沿用 KV 引用与批次准入。
4. 结果：填写模型、backend、负载、实际速率、短请求数量、P99、长等待、吞吐、缓存率及调度 CPU 开销，并给出运行目录。
5. 代价：解释没有改善的负载、成本拟合误差、候选限制漏掉短请求的可能、记录开销和阈值不能保证准入时间。
