## 主比较能说明什么

30 轮是 **一个 workload × 两个速率 × 三个种子 × 五种策略**，每轮 600 请求；不是两种 workload。聚合表与 30 个逐轮 CSV 一致。1.0 req/s 的 15 轮全部成功；0.5 req/s 的三轮各失败一个请求。

| 指标 | 0.5 req/s，三个 seed | 1.0 req/s，三个 seed |
| --- | --- | --- |
| K=0 短请求 P99 | 5.649 / 4.160 / 5.270 s | 4.617 / 4.669 / 4.352 s |
| 相对 HRRN 的短请求 P99 降幅 | 38.22%–44.26% | 97.30%–98.79% |
| 相对 FCFS 的长请求最大等待变化 | 增加 10.83%–27.05% | -3.14% / +0.68% / -1.91% |
| 相对 FCFS 的输出吞吐变化 | 基本持平，失败轮还受成功数影响 | 增加约 0.98%–2.50% |
| K=0 排序累计 CPU | 0.51–0.83 s | 10.06–11.33 s |

P99 改善主要反映等待重新分配，不是 GPU 计算加速同等比例。0.5 req/s 的 LPM/HRRN 没有策略回退，K=0 仍有收益，说明收益不能完全归因于原生回退。1.0 req/s 的 HRRN 约 16%–33%、LPM 约 49%–50% 的排序调用发生回退。

## 必须保留的解释

- 短请求原始输入不超过 2048 token，长请求至少 8192 token。历史 prefix 300 请求轮约 99–108 个成功短请求，600 请求主比较约 209–213 个。分行报告各 seed，不平均 P99 冒充总体 P99。
- 20260910 的 `first-run`、`short-input-mixed-r1-s1`、`short-remaining-mixed-r1-s1`、`hrrn-prefix-r4-s1` 各失败一个请求。`finished` 只表示运行流程结束；缺失服务端记录不是等待为零。
- 主比较 `r05/s2/fcfs`、`r05/s3/lpm`、`r05/s3/dfs-weight` 各失败一个请求。后两轮重试成功；FCFS 原始轮及三次重试仍各失败一个，不应称为已经排除的偶发问题。失败 rid、连接与日志片段待补，不继续盲目重跑。DFS 的长等待最大值从原始约 43.25 s 变为重试约 84.79 s，重试不能覆盖原始结果。
- K 限制普通候选评分，不限制所有扫描和准入匹配；K=0 表示全候选。总调度、排序、评分、准入准备是嵌套计时，不能相加。策略回退与请求重新入队分别统计。
- trace/no-trace 仅有 prefix、K=64、seed=2 单轮对照：短请求 P99 相差约 0.27 s（0.12%），吞吐约 0.05%。不能外推为 K=0 或所有负载下开销可忽略。
- `hot-prefix` 的短请求 P99 约 2.47 s，两个策略近似持平，只有 47 个成功短请求。`long-wait` 的长请求最大等待只有 0.33/0.45 **ms**，没有形成有效长等待压力，不能证明抗饥饿。`burst-decode` 中 K=0 短请求 P99 下降约 77.28%，长请求最大等待增加约 3.48%，吞吐增加约 0.78%；仅一个 seed、两个策略，发送偏差 P99 约 122–130 ms。
- 成本标定关闭 overlap，性能实验保持默认 overlap。留出 MAE=3.165 ms，Spearman=0.9683；仅按 R 的留出 Spearman 同样为 0.9683。同训练集拟合常数与 R 的非负线性模型，留出 MAE 约 76.47 ms。绝对耗时预测、排序能力与在线收益是三个不同结论。
- 300000 ms 阈值仍触发 aging；不能把 K=64、aged-cost 的约 425.66 s P99 与 K=0 主比较的 4.67 s 直接归因于成本模型。纯评分对照须同 K、同输入、同阈值且实际 aged=0。
- 20260911 两个 planned=0 的文本轮无效；20260914 两轮均 3/3 成功。回答一致、乘法得到 391、一个回答达到 256 token 上限等是服务器人工报告，正文待补。三题功能观察不代表质量基准。
- FlashInfer JIT 与 K=128 OOM 是环境／显存占用问题，不算策略性能样本。失败日志由服务器保留，归档未上传。

20260911 有 48 个逐轮 CSV：30 主比较、4 候选补充、2 trace、2 负载探索、2 aging 成本、6 补充 workload、2 无效文本。20260914 有 7 个：5 次性能重试、2 次有效文本。聚合 CSV 不另计实验次数。
